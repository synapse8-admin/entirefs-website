Design requirements

Use the following colours from the Entire Financial Services brand guidelines:

Section background: #D7DCC7
Primary headings and body text: #022F35
Icons and buttons: #0D6851
Button hover or small accent details: #AED137

Design the section to feel warm, calm, professional and focused on retirement planning.

Use generous vertical spacing and keep the content within the same maximum-width container used by the rest of the homepage.

Display the section heading and introduction centred above the service columns.

Use simple, consistent line-style icons. Do not use large illustrations or photographs.

Separate the three service columns using subtle vertical dividers on desktop. Remove the vertical dividers on mobile and use subtle horizontal spacing or dividers instead.

Keep all three descriptions visually balanced and approximately the same height.

Style each Learn more button consistently with the website’s existing buttons. Include a subtle hover transition.

Responsive behaviour
Desktop: three services displayed in one horizontal row
Tablet: three columns where space allows, otherwise use a clean stacked layout
Mobile: one service per row
Maintain appropriate padding and readable font sizes across all screen sizes
Ensure buttons are easy to tap on mobile
Accessibility requirements
Use semantic HTML
Include descriptive accessible labels for icons
Maintain sufficient colour contrast
Ensure all buttons and links are keyboard accessible
Add visible keyboard focus states
